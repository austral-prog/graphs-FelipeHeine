Line Plot¶

This graph shows how a quadratic function grows as x increases. The curve illustrates a non-linear trend where values increase faster over time. I chose a line plot because it is ideal for visualizing continuous data and mathematical functions.

In [3]:
# Generate data
x = np.arange(0, 10)
y = x**2

# Create plot
plt.plot(x, y, color='blue', marker='o', linestyle='--', linewidth=2, label='y = x²')

# Labels and title
plt.title('Quadratic Growth Over Time')
plt.xlabel('X values (units)')
plt.ylabel('Y values (units)')

# Legend
plt.legend()

# Save image
plt.savefig('imgs/line_plot.png', dpi=300, bbox_inches='tight')

plt.show()

Bar Chart¶

Histogram¶

This histogram shows the distribution of randomly generated data. It helps visualize how frequently values occur within certain ranges. I chose a histogram because it is ideal for understanding data distribution.

In [5]:
# Generate random data
data = np.random.randn(1000)

# Create histogram
plt.hist(data, bins=30, color='purple', edgecolor='black', label='Frequency')

# Labels and title
plt.title('Distribution of Random Data')
plt.xlabel('Value')
plt.ylabel('Frequency')

# Legend
plt.legend()

# Save image
plt.savefig('imgs/histogram.png', dpi=300, bbox_inches='tight')

plt.show()

Box Plot¶

This box plot summarizes the distribution of two datasets. It displays median, quartiles, and potential outliers in a compact form. I chose a box plot because it is useful for comparing distributions statistically.

# Generate data
data1 = np.random.randn(100)
data2 = np.random.randn(100) + 2

plt.xlabel('Datasets')
plt.ylabel('Values')
